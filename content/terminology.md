# 用語集

| 用語 | 意味 | 言い換えの例 |
| --- | --- | --- |
| 展示ルーム | 写真や動画を飾った 1 つの部屋。作品一覧のカード 1 枚に当たる | 作品、部屋、ルーム |
| 素材 | アップロードした写真や動画 | ファイル、メディア、画像、ムービー |
| 面 | 素材を飾る壁や床のひとつ | 壁、床 |
| 変換 | アップロードした動画を、どの端末でも再生できる形にする処理 | エンコード、処理中 |
| 公開範囲 | 展示ルームを誰に見せるかの設定 (非公開 / パス限定 / 全体公開) | 公開設定、見せる相手 |
| 公開パス | パス限定の展示ルームを開くための 6 桁の数字 | パスワード、暗証番号 |
| 共有リンク | 展示ルームを見るための URL | URL、リンク |
| 表示名 | 全体公開の展示ルームに表示される、作った人の名前 | ニックネーム、ユーザー名 |
| ゴミ箱 | 削除した展示ルームが 14 日間残る場所 | 削除済み |
