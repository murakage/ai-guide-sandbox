# ハコニワ Studio 利用者ガイド

ハコニワ Studio は、写真や動画を壁に飾った「展示ルーム」を作り、Web で公開するためのツールです。このガイドは、利用者が画面を操作して展示ルームを作成・編集・公開するための手引きです。

> このサイトは、AI 経由でガイドを届ける仕組みを試すための **架空のアプリ** のガイドです。

## ガイドの構成

| ページ | 内容 |
| --- | --- |
| [はじめかた](getting-started.html) | アカウント登録から、最初の展示ルームを公開するまで |
| [作品一覧画面](works-list.html) | 展示ルームの作成・複製・削除・ゴミ箱 |
| [編集画面](editor.html) | 壁と床への写真・動画の配置、アップロード、プレビュー |
| [公開設定](publish.html) | 公開範囲、公開パス、共有リンク |
| [よくあるつまずき](troubleshooting.html) | 動画が再生されない、公開できない などの対処 |
| [用語集](terminology.html) | このガイドで使う言葉の意味 |

## 画面構成の全体像

サインインすると、次の 3 つの画面を使います。

1. **作品一覧画面** (`/works`) — 自分の展示ルームが並ぶ画面。ここから作成・編集・公開設定に進みます。
2. **編集画面** (`/works/{作品ID}/editor`) — 展示ルームの壁と床に、写真や動画を配置します。
3. **公開設定画面** (`/works/{作品ID}/publish`) — 誰に見せるかを決めて、共有リンクを発行します。

どの画面でも、ヘッダー右端の **「?」ボタン** から、その画面のガイドを開いたり、AI に質問したりできます。
